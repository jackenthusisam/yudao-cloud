# AI 模块 AI 编码规范

## 模块概述
- **错误码段**: 1-040-xxx-xxx (注：与MES同段，需注意区分)
- **模块角色**: AI大模型（API密钥、模型管理、聊天对话）

## 子模块结构
```
yudao-module-ai/
├── yudao-module-ai-api/        # API接口
│   └── enums/ErrorCodeConstants.java
└── yudao-module-ai-server/     # 服务实现
```

## 主要功能域

### API密钥管理
- 密钥创建/禁用
- 密钥权限控制

### 模型管理
- 模型配置 (`ai_model`)
- 模型类型（对话、 embedding 等）
- 默认模型设置

### 聊天角色
- 角色创建 (`ai_chat_role`)
- 角色启用/禁用

### 聊天会话
- 会话管理 (`ai_chat_conversation`)
- 消息记录 (`ai_chat_message`)
- 对话上下文

## 错误码示例
```java
// API密钥 1-040-000-000
ErrorCode API_KEY_NOT_EXISTS = new ErrorCode(1_040_000_000, "API密钥不存在");
ErrorCode API_KEY_DISABLE = new ErrorCode(1_040_000_001, "API密钥已禁用！");

// 模型 1-040-001-000
ErrorCode MODEL_NOT_EXISTS = new ErrorCode(1_040_001_000, "模型不存在!");
ErrorCode MODEL_DISABLE = new ErrorCode(1_040_001_001, "模型({})已禁用!");

// 聊天角色 1-040-002-000
ErrorCode CHAT_ROLE_NOT_EXISTS = new ErrorCode(1_040_002_000, "聊天角色不存在");

// 聊天会话 1-040-003-000
ErrorCode CHAT_CONVERSATION_NOT_EXISTS = new ErrorCode(1_040_003_000, "对话不存在!");
```

## 支持的模型类型
- 对话模型 (chat)
- Embedding 模型
- 图片生成模型
