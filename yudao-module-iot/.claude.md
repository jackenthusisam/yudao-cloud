# IoT 模块 AI 编码规范

## 模块概述
- **错误码段**: 1-050-xxx-xxx
- **模块角色**: 物联网（设备管理、产品管理、物模型、数据采集）

## 子模块结构
```
yudao-module-iot/
├── yudao-module-iot-api/        # API接口
├── yudao-module-iot-core/       # 核心业务
├── yudao-module-iot-gateway/    # 网关相关
└── yudao-module-iot-server/     # 服务实现
```

## 主要功能域

### 产品管理
- 产品创建/编辑 (`iot_product`)
- 产品标识 (ProductKey)
- 物模型定义
- 产品状态 (开发/已发布)

### 物模型
- 属性定义
- 服务定义
- 事件定义
- 标识符唯一性校验

### 设备管理
- 设备注册 (`iot_device`)
- 设备连接
- 子设备管理
- 设备拓扑
- 设备影子

### 数据采集
- 属性上报
- 消息队列
- TDengine 时序存储

## 错误码示例
```java
// 产品相关 1-050-001-000
ErrorCode PRODUCT_NOT_EXISTS = new ErrorCode(1_050_001_000, "产品不存在");
ErrorCode PRODUCT_KEY_EXISTS = new ErrorCode(1_050_001_001, "产品标识已经存在");

// 物模型 1-050-002-000
ErrorCode THING_MODEL_NOT_EXISTS = new ErrorCode(1_050_002_000, "产品物模型不存在");
ErrorCode THING_MODEL_IDENTIFIER_EXISTS = new ErrorCode(1_050_002_002, "存在重复的功能标识符");

// 设备 1-050-003-000
ErrorCode DEVICE_NOT_EXISTS = new ErrorCode(1_050_003_000, "设备不存在");
ErrorCode DEVICE_NAME_EXISTS = new ErrorCode(1_050_003_001, "设备名称在同一产品下必须唯一");
```

## 特殊规范

### 设备标识
- ProductKey - 产品标识符
- DeviceKey - 设备标识符
- DeviceSecret - 设备密钥

### 状态管理
- 设备在线/离线
- 产品开发/发布状态
