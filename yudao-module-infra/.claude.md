# Infra 模块 AI 编码规范

## 模块概述
- **错误码段**: 1-001-xxx-xxx
- **模块角色**: 基础设施（代码生成、文件存储、参数配置、定时任务等）

## 子模块结构
```
yudao-module-infra/
├── yudao-module-infra-api/        # API接口
│   └── enums/ErrorCodeConstants.java
└── yudao-module-infra-server/     # 服务实现
```

## 主要功能域

### 参数配置
- 键值对配置管理
- 系统内置配置保护

### 定时任务
- JobHandler 实现
- Cron 表达式校验
- 任务状态管理

### 文件存储
- 本地存储
- MinIO
- 阿里云OSS
- 腾讯云COS
- 七牛云

### 代码生成
- 表结构导入
- 字段配置
- 主子表生成
- 同步机制

### API 错误日志
- 请求追踪
- 异常记录

## 错误码示例
```java
// 参数配置 1-001-000-000
ErrorCode CONFIG_NOT_EXISTS = new ErrorCode(1_001_000_001, "参数配置不存在");
ErrorCode CONFIG_KEY_DUPLICATE = new ErrorCode(1_001_000_002, "参数配置 key 重复");

// 定时任务 1-001-001-000
ErrorCode JOB_NOT_EXISTS = new ErrorCode(1_001_001_000, "定时任务不存在");
ErrorCode JOB_CRON_EXPRESSION_VALID = new ErrorCode(1_001_001_005, "CRON 表达式不正确");

// 文件相关 1-001-003-000
ErrorCode FILE_NOT_EXISTS = new ErrorCode(1_001_003_001, "文件不存在");

// 代码生成器 1-001-004-000
ErrorCode CODEGEN_TABLE_EXISTS = new ErrorCode(1_001_004_002, "表定义已经存在");
```

## 权限标识格式
- `infra:config:create`
- `infra:config:update`
- `infra:job:create`
- `infra:file:upload`
