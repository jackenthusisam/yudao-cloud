# ERP 模块 AI 编码规范

## 模块概述
- **错误码段**: 1-030-xxx-xxx
- **模块角色**: 企业资源计划（采购、销售、库存、财务）

## 子模块结构
```
yudao-module-erp/
├── yudao-module-erp-api/        # API接口
│   └── enums/ErrorCodeConstants.java
└── yudao-module-erp-server/     # 服务实现
```

## 主要功能域

### 供应商管理
- 供应商档案 (`erp_supplier`)
- 供应商启用状态校验

### 采购模块
- 采购订单 (`erp_purchase_order`)
- 采购入库 (`erp_purchase_in`)
- 采购退货 (`erp_purchase_return`)

### 销售模块
- 销售订单 (`erp_sale_order`)
- 销售出库 (`erp_sale_out`)
- 销售退货 (`erp_sale_return`)

### 库存管理
- 库房管理 (`erp_warehouse`)
- 库存快照
- 库存盘点

### 财务管理
- 客户账户 (`erp_customer`)
- 供应商账户

### 生产管理
- 生产工单
- 生产投料

## 错误码示例
```java
// 供应商 1-030-100-000
ErrorCode SUPPLIER_NOT_EXISTS = new ErrorCode(1_030_100_000, "供应商不存在");

// 采购订单 1-030-101-000
ErrorCode PURCHASE_ORDER_NOT_EXISTS = new ErrorCode(1_030_101_000, "采购订单不存在");
ErrorCode PURCHASE_ORDER_DELETE_FAIL_APPROVE = new ErrorCode(1_030_101_001, "采购订单({})已审核，无法删除");

// 采购入库 1-030-102-000
ErrorCode PURCHASE_IN_NOT_EXISTS = new ErrorCode(1_030_102_000, "采购入库单不存在");
```

## 业务特点

### 审核流程
- 采购/销售单据需要审核后才能操作
- 审核后不可修改，需反审核

### 库存校验
- 入库数量不超过订单最大允许数量
- 退货数量不超过已入库数量
