# 芋道 Cloud 项目 AI 编码规范

## 项目概述

- **项目名称**: yudao-cloud (芋道)
- **技术栈**: Java 17 + Spring Boot 3.x + Spring Cloud Alibaba 微服务架构
- **项目类型**: 微服务后台管理系统
- **官方文档**: <https://cloud.iocoder.cn/quick-start/>

## 技术规范

### 技术版本
- Java: 17
- Spring Boot: 3.5.x
- Spring Cloud: 2024.x
- MyBatis Plus: 3.5.x
- 数据库: MySQL 8.x (兼容 PostgreSQL, Oracle, SQL Server, MariaDB, 达梦, TiDB)
- 注册/配置中心: Nacos
- 定时任务: XXL-Job
- 服务保障: Sentinel
- 分布式事务: Seata

### 项目模块结构
```
yudao/
├── yudao-dependencies/     # 统一依赖版本管理
├── yudao-framework/         # 框架层（通用组件）
│   ├── yudao-common/        # 公共工具类
│   └── yudao-spring-boot-starter-*/  # 各starter组件
├── yudao-gateway/          # 网关服务
├── yudao-server/           # 主启动模块
└── yudao-module-*/         # 业务模块
    ├── *-api/              # API接口定义（对外暴露）
    └── *-server/           # 服务实现
```

### 模块命名规范
- API模块: `yudao-module-{name}-api`
- Server模块: `yudao-module-{name}-server`
- 模块名使用小写，用 `-` 分隔

## 编码规范

### 包结构规范
每个业务模块的包结构遵循：
```
cn.iocoder.yudao.module.{module}
├── api/                    # API实现（对外暴露）
├── controller/
│   ├── admin/              # 管理后台API
│   │   └── vo/             # 请求/响应VO
│   └── app/                # C端APP API
│       └── vo/
├── service/                # 服务层
│   ├── {entity}Service.java
│   └── {entity}ServiceImpl.java
├── dal/
│   ├── dataobject/         # DO数据对象
│   └── mysql/              # Mapper
├── convert/                 # MapStruct转换器
├── enums/                   # 枚举定义（放在-api模块）
└── framework/               # 模块内框架配置
```

### 类命名规范
| 类型 | 命名规则 | 示例 |
|------|----------|------|
| DO数据对象 | `{Entity}DO` | `ProductBrandDO` |
| Mapper | `{Entity}Mapper` | `ProductBrandMapper` |
| Service接口 | `{Entity}Service` | `ProductBrandService` |
| Service实现 | `{Entity}ServiceImpl` | `ProductBrandServiceImpl` |
| Controller | `{Entity}Controller` | `ProductBrandController` |
| 创建请求VO | `{Entity}CreateReqVO` | `ProductBrandCreateReqVO` |
| 更新请求VO | `{Entity}UpdateReqVO` | `ProductBrandUpdateReqVO` |
| 响应VO | `{Entity}RespVO` | `ProductBrandRespVO` |
| 分页请求VO | `{Entity}PageReqVO` | `ProductBrandPageReqVO` |
| 列表请求VO | `{Entity}ListReqVO` | `ProductBrandListReqVO` |
| 转换器 | `{Entity}Convert` | `ProductBrandConvert` |

### DO 数据对象规范
```java
@TableName("product_brand")
@KeySequence("product_brand_seq") // Oracle/PostgreSQL/H2主键自增
@Data @EqualsAndHashCode(callSuper = true)
@ToString(callSuper = true)
@Builder @NoArgsConstructor @AllArgsConstructor
public class ProductBrandDO extends BaseDO {
    @TableId
    private Long id;
    private String name;
    // 枚举字段使用Integer类型，注释标注枚举类
    private Integer status; // 枚举 {@link CommonStatusEnum}
}
```

### Controller 规范
```java
@Tag(name = "管理后台 - 商品品牌")
@RestController
@RequestMapping("/product/brand")
@Validated
public class ProductBrandController {
    @Resource
    private ProductBrandService brandService;

    @PostMapping("/create")
    @Operation(summary = "创建品牌")
    @PreAuthorize("@ss.hasPermission('product:brand:create')")
    public CommonResult<Long> createBrand(@Valid @RequestBody ProductBrandCreateReqVO createReqVO) {
        return success(brandService.createBrand(createReqVO));
    }
}
```

### Service 实现规范
```java
@Service
@Validated
public class ProductBrandServiceImpl implements ProductBrandService {
    @Resource
    private ProductBrandMapper brandMapper;

    @Override
    public Long createBrand(ProductBrandCreateReqVO createReqVO) {
        validateBrandNameUnique(null, createReqVO.getName());
        ProductBrandDO brand = ProductBrandConvert.INSTANCE.convert(createReqVO);
        brandMapper.insert(brand);
        return brand.getId();
    }

    @VisibleForTesting
    public void validateBrandNameUnique(Long id, String name) { ... }
}
```

### Mapper 规范
```java
@Mapper
public interface ProductBrandMapper extends BaseMapperX<ProductBrandDO> {
    default PageResult<ProductBrandDO> selectPage(ProductBrandPageReqVO reqVO) {
        return selectPage(reqVO, new LambdaQueryWrapperX<ProductBrandDO>()
                .likeIfPresent(ProductBrandDO::getName, reqVO.getName())
                .eqIfPresent(ProductBrandDO::getStatus, reqVO.getStatus())
                .betweenIfPresent(ProductBrandDO::getCreateTime, reqVO.getCreateTime())
                .orderByDesc(ProductBrandDO::getId));
    }
}
```

### 错误码规范
错误码定义在 `*-api/src/.../enums/ErrorCodeConstants.java`
```java
public interface ErrorCodeConstants {
    // 格式：模块-分类-编号  如 1-008-002-000
    // 模块编号：商品=1-008, 促销=1-009, 交易=1-010
    ErrorCode BRAND_NOT_EXISTS = new ErrorCode(1_008_002_000, "品牌不存在");
    ErrorCode BRAND_NAME_EXISTS = new ErrorCode(1_008_002_002, "品牌名称已存在");
}
```

### 转换器规范
使用 MapStruct 进行对象转换：
```java
@Mapper
public interface ProductBrandConvert {
    ProductBrandConvert INSTANCE = Mappers.getMapper(ProductBrandConvert.class);
    ProductBrandDO convert(ProductBrandCreateReqVO bean);
    ProductBrandRespVO convert(ProductBrandDO bean);
    List<ProductBrandRespVO> convertList(List<ProductBrandDO> list);
    PageResult<ProductBrandRespVO> convertPage(PageResult<ProductBrandDO> page);
}
```

## API 设计规范

### URL 路径规范
- 管理后台: `/product/brand/create`
- C端APP: `/app/product/brand/create`
- 命名使用小写 + 中划线

### 返回格式
```java
// 成功
return success(result);
// 失败
throw exception(ERROR_CODE);
```

### 分页返回
```java
public CommonResult<PageResult<ProductBrandRespVO>> getBrandPage(@Valid ProductBrandPageReqVO pageVO) {
    PageResult<ProductBrandDO> pageResult = brandService.getBrandPage(pageVO);
    return success(ProductBrandConvert.INSTANCE.convertPage(pageResult));
}
```

## 数据库规范

### 表名前缀
- 商品相关: `product_*`
- 品牌: `product_brand`
- 分类: `product_category`

### 字段命名
- 使用下划线命名
- 状态字段: `status` (Integer)
- 创建时间: `create_time`
- 更新时间: `update_time`

### 通用枚举
- `CommonStatusEnum`: ENABLE=0, DISABLE=1

## 安全规范

### 权限控制
```java
@PreAuthorize("@ss.hasPermission('product:brand:create')")
```
权限字符串格式: `{module}:{entity}:{operation}`

### 参数校验
- 使用 `@Valid` 注解
- VO类使用 `@Schema` 注解描述字段

## 依赖规范

### 模块间依赖
- `*-server` 可依赖 `*-api`
- `*-server` 不可直接依赖其他 `*-server`
- 跨模块调用使用 RPC

### API 模块
仅包含：
- 对外暴露的 API 接口
- 枚举类
- 通用常量
- 错误码定义
