### VO 继承规范
- CreateReqVO 继承 BaseVO
- UpdateReqVO 继承 BaseVO
- BaseVO 包含所有通用字段
- 子 VO 只包含差异化字段

```java
// BaseVO 包含: name, picUrl, sort, description, status
public class ProductBrandBaseVO { ... }

// CreateReqVO 继承 BaseVO，无额外字段
public class ProductBrandCreateReqVO extends ProductBrandBaseVO { }

// UpdateReqVO 继承 BaseVO，无额外字段
public class ProductBrandUpdateReqVO extends ProductBrandBaseVO { }
```

### 数据校验规则
- 必填字段: `@NotNull` + `@Schema(requiredMode = REQUIRED)`
- 字符串长度: `@Size(min=, max=)`
- 数字范围: `@Min` / `@Max`

### 业务校验
在 ServiceImpl 中进行业务校验，如品牌名称唯一性：
```java
@VisibleForTesting
public void validateBrandNameUnique(Long id, String name) {
    ProductBrandDO brand = brandMapper.selectByName(name);
    if (brand == null) return;
    if (id == null || !brand.getId().equals(id)) {
        throw exception(BRAND_NAME_EXISTS);
    }
}
```
