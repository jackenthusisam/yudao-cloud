# MES 模块 AI 编码规范

## 模块概述
- **错误码段**: 1-040-xxx-xxx
- **模块角色**: 制造执行系统（物料、工艺、生产、工序、质量）

## 子模块结构
```
yudao-module-mes/
├── yudao-module-mes-api/        # API接口
│   └── enums/ErrorCodeConstants.java
└── yudao-module-mes-server/     # 服务实现
```

## 主要功能域

### 基础数据
- 物料分类 (`mes_md_item_type`)
- 计量单位 (`mes_md_unit_measure`)
- 物料档案 (`mes_md_item`)
- 工艺路线 (`mes_md_workstation`)
- 工序管理 (`mes_md工序`)

### 生产管理
- 生产工单 (`mes_pro_order`)
- 生产投料
- 生产报工
- 生产入库

### 质量管理
- 质检方案
- 质检单据
- 质检指标

### 工序作业
- 工序计划
- 工序执行
- 工序转移

## 错误码示例
```java
// 物料分类 1-040-100-000
ErrorCode MD_ITEM_TYPE_NOT_EXISTS = new ErrorCode(1_040_100_000, "物料分类不存在");
ErrorCode MD_ITEM_TYPE_NAME_DUPLICATE = new ErrorCode(1_040_100_004, "同一父分类下已存在该名称的分类");

// 计量单位 1-040-101-000
ErrorCode MD_UNIT_MEASURE_NOT_EXISTS = new ErrorCode(1_040_101_000, "计量单位不存在");
ErrorCode MD_UNIT_MEASURE_CODE_DUPLICATE = new ErrorCode(1_040_101_001, "计量单位编码已存在");
```

## 业务特点

### 层级结构
- 物料分类树形结构
- 计量单位主辅单位关系

### 生产流程
- 工单 → 投料 → 报工 → 入库
- 工序顺序执行
