# Report 模块 AI 编码规范

## 模块概述
- **错误码段**: 1-003-xxx-xxx
- **模块角色**: 数据报表（GoView 大屏设计器）

## 子模块结构
```
yudao-module-report/
├── yudao-module-report-api/        # API接口
```

- 项目预览

### 组件管理
- 组件库
- 拖拽设计
- 组件属性配置

### 数据源
- 静态数据
- 动态API
