# Framework 模块 AI 编码规范

## 模块概述
框架层，封装通用能力，供所有业务模块复用。

## 子模块结构
```
yudao-framework/
├── yudao-common/                          # 公共工具类
├── yudao-spring-boot-starter-biz-*/        # 各业务 starter
└── 各 starter 说明
```

## 核心类说明

### BaseDO
所有数据对象的基类，包含：
- `id` - 主键
- `createTime` - 创建时间
- `updateTime` - 更新时间
- `creator` - 创建人
- `updater` - 更新人
- `deleted` - 逻辑删除标志

### BaseMapperX
MyBatis Plus 扩展 Mapper，提供：
- `selectPage` - 分页查询
- `selectList` - 列表查询
- `selectOne` - 单条查询

### LambdaQueryWrapperX
链式查询条件封装：
- `likeIfPresent` - 模糊查询
- `eqIfPresent` - 等值查询
- `betweenIfPresent` - 范围查询
- `orderByDesc/Asc` - 排序

### CommonResult
统一响应封装：
- `success(data)` - 成功响应
- `error(errorCode)` - 错误响应

### ErrorCode
错误码定义：
```java
new ErrorCode(代码, "消息")
// 如：new ErrorCode(1_002_000_000, "登录失败")
```

## 常用工具类
- `DateUtil` - 日期处理
- `StringUtil` - 字符串处理
- `BeanUtil` - Bean转换
- `CollectionUtil` - 集合处理

本模块定义框架规范，供业务模块遵循。
