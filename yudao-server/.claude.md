# Server 模块 AI 编码规范

## 模块概述
主启动模块，聚合所有业务模块的依赖。

## 模块职责
- 统一版本管理
- 依赖聚合
- 启动入口

## pom.xml 结构
```xml
<modules>
    <module>../yudao-dependencies</module>
    <module>../yudao-gateway</module>
    <module>../yudao-framework</module>
    <module>../yudao-module-system</module>
    <module>../yudao-module-infra</module>
    <module>../yudao-module-mall</module>
    <!-- ... 其他模块 -->
</modules>
```

## 配置文件
- `application.yml` - 主配置
- `bootstrap.yml` - 引导配置（连接 Nacos）

## 启动类
- `YudaoServerApplication.java` - 主启动类

## 环境配置
- dev - 开发环境
- test - 测试环境
- prod - 生产环境

## 继承根项目规范
遵循根项目 `.claude.md` 中的通用编码规范。
