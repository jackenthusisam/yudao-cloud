# Gateway 模块 AI 编码规范

## 模块概述
网关服务，基于 Spring Cloud Gateway 实现统一入口。

## 配置规范

### 路由配置
```yaml
spring:
  cloud:
    gateway:
      routes:
        - id: product
          uri: lb://product-server
          predicates:
            - Path=/product/**
          filters:
            - StripPrefix=1
```

### 过滤器
- 登录 Token 校验
- 限流保护
- 跨域处理

## 路由模块映射

| 前缀 | 目标服务 |
|------|----------|
| `/system` | system-server |
| `/infra` | infra-server |
| `/product` | product-server |
| `/promotion` | promotion-server |
| `/bpm` | bpm-server |

## 安全配置
- 内部服务间调用使用内网路由
- 外部暴露接口需登录认证
- 敏感接口需权限校验
