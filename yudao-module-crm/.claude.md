# CRM 模块 AI 编码规范

## 模块概述
- **错误码段**: 1-020-xxx-xxx
- **模块角色**: 客户关系管理（线索、商机、合同、客户、联系人）

## 子模块结构
```
yudao-module-crm/
├── yudao-module-crm-api/        # API接口
│   └── enums/ErrorCodeConstants.java
└── yudao-module-crm-server/     # 服务实现
```

## 主要功能域

### 线索管理
- 线索录入
- 线索转化
- 线索分配

### 商机管理
- 商机创建
- 商机跟进
- 商机状态变更

### 合同管理
- 合同创建/编辑
- 合同审核
- 合同状态 (草稿→审核中→已审核)

### 客户管理
- 客户档案
- 客户跟进
- 客户共享

### 联系人管理
- 联系人信息
- 联系记录

### 回款管理
- 回款计划
- 回款记录

## 错误码示例
```java
// 合同管理 1-020-000-000
ErrorCode CONTRACT_NOT_EXISTS = new ErrorCode(1_020_000_000, "合同不存在");
ErrorCode CONTRACT_UPDATE_FAIL_NOT_DRAFT = new ErrorCode(1_020_000_001, "合同更新失败，原因：合同不是草稿状态");

// 线索管理 1-020-001-000
ErrorCode CLUE_NOT_EXISTS = new ErrorCode(1_020_001_000, "线索不存在");
ErrorCode CLUE_TRANSFORM_FAIL_ALREADY = new ErrorCode(1_020_001_001, "线索已经转化过了");

// 商机管理 1-020-002-000
ErrorCode BUSINESS_NOT_EXISTS = new ErrorCode(1_020_002_000, "商机不存在");
```

## 业务特点

### 审核流程
- 合同需要提交审核
- 审核中状态不可修改

### 数据关联
- 商机可关联合同
- 合同关联回款计划
