# BPM 模块 AI 编码规范

## 模块概述
- **错误码段**: 1-009-xxx-xxx
- **模块角色**: 工作流程（Flowable 流程引擎）

## 子模块结构
```
yudao-module-bpm/
├── yudao-module-bpm-api/        # API接口
│   └── enums/ErrorCodeConstants.java
└── yudao-module-bpm-server/     # 服务实现
```

## 主要功能域

### 流程模型
- 模型创建/编辑
- BPMN 流程设计
- 表单配置
- 审批人设置

### 流程定义
- 部署管理
- 版本控制
- 流程图查看

### 流程任务
- 发起申请
- 审批处理
- 任务转交
- 任务取消

### OA办公
- 请假申请
- 费用报销
- 外出申请

## 错误码示例
```java
// OA 流程模块 1-009-001-000
ErrorCode OA_LEAVE_NOT_EXISTS = new ErrorCode(1_009_001_001, "请假申请不存在");

// 流程模型 1-009-002-000
ErrorCode MODEL_KEY_EXISTS = new ErrorCode(1_009_002_000, "已经存在流程标识为【{}】的流程");
ErrorCode MODEL_NOT_EXISTS = new ErrorCode(1_009_002_001, "流程模型不存在");

// 流程定义 1-009-003-000
ErrorCode PROCESS_DEFINITION_KEY_NOT_MATCH = new ErrorCode(1_009_003_000, "流程定义的标识期望是({})");
```

## 权限标识格式
- `bpm:process:create`
- `bpm:task:approve`
- `bpm:oa-leave:create`

## 流程相关表
- `bpm_process_definition` - 流程定义
- `bpm_task` - 任务记录
- `bpm_listener` - 监听器
