# System 模块 AI 编码规范

## 模块概述
- **错误码段**: 1-002-xxx-xxx
- **模块角色**: 系统管理（用户、角色、菜单、权限、认证等）

## 子模块结构
```
yudao-module-system/
├── yudao-module-system-api/        # API接口
│   └── enums/ErrorCodeConstants.java
└── yudao-module-system-server/     # 服务实现
```

## 主要功能域

### 认证模块 (AUTH)
- 登录/登出
- 注册
- 短信验证码登录
- 社交登录（微信、钉钉等）

### 权限模块
- 用户管理 (`admin_user`)
- 角色管理 (`system_role`)
- 菜单管理 (`system_menu`)
- 权限分配

### 基础设施
- 部门管理 (`system_dept`)
- 岗位管理 (`system_post`)
- 字典数据 (`system_dict_data`)
- 字典类型 (`system_dict_type`)

### 日志
- 登录日志 (`system_login_log`)
- 操作日志 (`systemOperate_log`)

### 第三方集成
- 邮件发送
- 短信发送
- 通知消息
- OAuth2客户端

## 错误码示例
```java
// AUTH 模块 1-002-000-000
ErrorCode AUTH_LOGIN_BAD_CREDENTIALS = new ErrorCode(1_002_000_000, "登录失败，账号密码不正确");
ErrorCode AUTH_LOGIN_USER_DISABLED = new ErrorCode(1_002_000_001, "登录失败，账号被禁用");

// 菜单模块 1-002-001-000
ErrorCode MENU_NAME_DUPLICATE = new ErrorCode(1_002_001_000, "已经存在该名字的菜单");

// 角色模块 1-002-002-000
ErrorCode ROLE_NOT_EXISTS = new ErrorCode(1_002_002_000, "角色不存在");

// 用户模块 1-002-003-000
ErrorCode USER_NOT_EXISTS = new ErrorCode(1_002_003_003, "用户不存在");
```

## 权限标识格式

- `system:user:update`
- `system:user:delete`

- `system:role:create`

- `/system/auth/login`

- `/system/role/page`

## 继承根项目规范
本模块遵循根项目 `.claude.md` 中的通用编码规范，包括：
- DO/Mapper/Service/Controller 命名
- VO 继承结构 (BaseVO → CreateReqVO/UpdateReqVO)
- MapStruct 转换器
- LambdaQueryWrapperX 查询封装
